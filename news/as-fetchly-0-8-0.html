AS Fetchly 0.8.0: one file to install, one click to remove

AS Fetchly 0.8.0 ships as one setup file. Run it and the app installs itself and opens. If an older version is already installed, it is replaced automatically.

  • Uninstall from Windows Settings, or with the new Uninstall button inside the app.
  • Your settings stay in your user folder unless you delete them.
  • English and Urdu interface.

Get it on the download section. If Windows shows a "protected your PC" screen, click More info, then Run anyway.
