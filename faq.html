Questions, answered.

Can't find what you need? Message us and a real person will reply.

What is AS Fetchly?

A Windows app that downloads YouTube and TikTok videos, playlists and whole profiles in quality from 144p up to 4K, in MP4, MKV, WebM, MP3 or M4A.

Is it free?

Yes, there is a free plan for single videos up to 720p. Pro unlocks playlists and profiles, saved accounts with daily auto-download, video cutting and quality up to 4K.

How do I get Pro?

Message us on WhatsApp. After payment (JazzCash or Easypaisa) you receive a licence key to enter inside the app.

Windows says it protected my PC. Is the file safe?

Windows shows this for new publishers that have not yet bought a code-signing certificate. Click More info, then Run anyway. Only download from this website or our official releases page.

How do I update or uninstall?

Run the newer setup file and it replaces the old version automatically. To uninstall, use Windows Settings, Apps, or the Uninstall button in the app.

How many devices can one licence use?

Each key allows a limited number of devices, set when you buy. If you change your computer, contact us and we will move it.

Does Pro need internet?

The licence is checked online from time to time. If you are offline, it keeps working for up to 7 days.

Is it legal to use?

Download only content you own or have permission to save, and follow each platform's terms. You are responsible for how you use the software.

Which systems and languages are supported?

Windows 10 and 11 (64-bit). The app is available in English and Urdu.

What data do you collect?

AS Fetchly runs on your computer. For Pro, we receive your licence key and a device ID to verify the licence. See the Privacy page for details.

Where is AS Forge from, and how do I reach you?

See the Contact page for WhatsApp and email.
